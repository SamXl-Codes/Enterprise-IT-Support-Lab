# Runbook: meeting-room AV outage

1. Log room, time, severity, affected meeting and exact symptoms.
2. Verify power, cabling, active input, device selection, network connectivity and firmware state.
3. Test the microphone, speakers and display with an approved local account, avoiding recording attendees.
4. Offer fallback access or an alternate room when the meeting is time-critical.
5. Reproduce the issue, capture non-sensitive diagnostics, document the fix and assign long-term action if recurring.
